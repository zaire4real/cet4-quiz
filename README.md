# CET-4 600 核心词抽考

在线使用：https://zaire4real.github.io/cet4-quiz/

一个单页抽考网站，词表为 CET-4 600 个核心词（附词性、中文义与常见搭配）。

## 玩法

- **20 题模式**：从所选范围随机抽 20 题，四选一，做完看成绩与错题
- **循环模式**：一直出题，整轮范围出完之前不重复，出完自动洗牌继续，随时可结束结算
- **方向**：英翻中 / 中翻英 / 混合随机
- **范围**：全部 600 词，或按 1–100、101–200……501–600 分段练
- **发音**：每题可播放英文读音（有道词典 → 字典音档 → Google 翻译发音 → 浏览器朗读，四段备援），每题附 Merriam-Webster 与 Google 翻译链接
- **单词表**：600 词可搜寻总表，每词可播放发音

中翻英题目在作答前会锁定发音键，避免一播就泄漏答案；答完后解锁。

## 说明

- 本站为纯静态单页（`index.html`），无后端，答题记录只存在浏览器本地
- 发音第一顺位是有道词典（中国大陆可访问）；备援中的 Google 翻译在中国大陆无法访问
- 词表来源：CET-4 425 完整背诵资料（600 核心词）
